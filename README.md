# VectorPad

Eine einfache Vektorgrafik-App für den Unterricht – läuft komplett im Browser, auch auf dem iPad, ohne Login.

**Funktionen:** Rechteck, Ellipse, Dreieck, Linie, Text · Rand- und Füllfarbe, Randstärke · Auswählen, Verschieben, Skalieren · Ebenen (ganz nach hinten, zurück, vor, ganz nach vorne) · Duplizieren, Löschen · Raster · Rückgängig/Wiederholen · Speichern als SVG (beim erneuten Öffnen bleiben alle Formen bearbeitbar) · PNG-Export · automatische Zwischenspeicherung im Browser.

Die ganze App steckt in `index.html`.
